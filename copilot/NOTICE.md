# Source provenance

This is an independent hard fork. There is no automatic upstream
synchronization or plugin release dependency.

The implementation derives from Arthur Sommer's MIT-licensed
[`arthur-sommer-etc/cliproxyapi-copilot-plugin`](https://github.com/arthur-sommer-etc/cliproxyapi-copilot-plugin)
v0.3.3, ported to the CLIProxyAPI v8.0.48 SDK and extended with an
authenticated quota management endpoint. The MIT copyright and license are
retained in the repository's NOTICE.

CLIProxyAPI is a separate host and a pinned SDK dependency, not forked here.
